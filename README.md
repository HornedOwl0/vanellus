# Vanellus

###### (The name *Vanellus* was chosen out of necessity and stuck as a reference for *Vanellus Chilensis*, a common bird in Brazil.)

Vanellus is a final project in Industrial Automation Consisting of a whiteboard erasing robot
This repository houses primitives and simple libraries needed for Vanellus (among other less important files):

***Hedera***: Two-Wire Primitives

***Helianthus***: ADC Primitives

***Hyacinthus***: GPIO Primitives

***Hydrangea***: Cooperative Scheduler

***Hibiscus***: USB CDC ACM debug interface

Since its origin ***Hibiscus*** remains the most important and longest library for Vanellus.
